# Caio Lucas Teixeira Ferraz de Oliveira — microfísica de raios (descargas elétricas)

## 1.	Avaliação de esquemas de previsão de descargas elétricas em modelos de mesoescala: testar esquemas de parametrização de raios baseados em fluxo de gelo/graupel, comparando a atividade elétrica simulada com dados observados (ex.: GLM, LINET) sobre o Brasil.

## 2.	Relação entre microfísica convectiva e atividade elétrica simulada: investigar como a escolha do esquema de microfísica de nuvens afeta a taxa de descargas elétricas prevista em sistemas convectivos de mesoescala.

# Relação com a disciplina: os temas conectam a parametrização de microfísica convectiva a um produto derivado (descargas elétricas), ilustrando como escolhas de fechamento físico no modelo propagam incerteza para variáveis simuladas — tema de parametrizações físicas e sensibilidade de modelo.
